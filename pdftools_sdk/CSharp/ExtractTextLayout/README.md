About this kit
==============

This kit contains the ExtractTextLayout sample for the Pdftools SDK for C#. The Pdftools SDK is a comprehensive development library that lets developers integrate advanced PDF functionalities into in-house applications. Find more information about this kit in Pdftools [documentation portal](https://www.pdf-tools.com/docs/).

## Quick start

How to execute this sample:

**Prerequisite:**

Any supported version of .NET installed:
- .NET and .NET Core: 2.0, 2.1, 2.2, 3.0, 3.1, 5.0, 6.0, 7.0, 8.0, 9.0
- .NET Framework: 4.6.1, 4.6.2, 4.7, 4.7.1, 4.7.2, 4.8, 4.8.1

**Via command line:**

1. Execute in sample folder:
    `dotnet run --framework net8.0 --project PdfToolsExtractTextLayout.csproj <inputPath> <outputDir>`

**Via Visual Studio:**

1. At least Visual Studio 2022 installed
2. Double click on `PdfToolsExtractTextLayout.csproj`
3. Compile project in Visual Studio
4. Run:
    `PdfToolsExtractTextLayout.exe <inputPath> <outputDir>`
