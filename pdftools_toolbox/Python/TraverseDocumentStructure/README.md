About this kit
==============

This kit contains the TraverseDocumentStructure sample for the PdfTools SDK for Python. The Pdftools SDK is a comprehensive development library that lets developers integrate advanced PDF functionalities into in-house applications. Find more information about this kit in Pdftools [documentation portal](https://www.pdf-tools.com/docs/).

## Quick start

**Prerequisite:**

- Python 3.7 or higher
- On some systems, mostly Linux based ones, only Python 3 is installed and `python` is not aliased, so on these systems you need to run `python3` instead.

**Installation**

Install the package for the PdfTools SDK by executing:

```bash
pip install pdftools_toolbox
```
**Usage:**

To run the sample, use the following command:

```bash
python ./traverse_document_structure.py <input_path>
```

To get help, run the following command:

```bash
python ./traverse_document_structure.py -h
```

**Cross-Platform Compatibility:**

This sample is designed to be cross-platform compatible. It has been tested on Linux, macOS, and Windows.
